# Voke® — Site Institucional

Site institucional da **Voke®**, agência de marketing.

## Stack

- HTML + CSS + JS puros (sem framework, zero dependências)
- Deploy automático via Vercel

## Como subir

### Opção 1 — Vercel (recomendado)
1. Suba este repositório no GitHub
2. Acesse [vercel.com](https://vercel.com) → **Add New Project**
3. Importe o repositório
4. Framework Preset: **Other** (ou deixe em branco)
5. Clique em **Deploy** — pronto ✅

### Opção 2 — Vercel CLI
```bash
npm i -g vercel
vercel --prod
```

## Estrutura

```
voke-site/
├── index.html      # Site completo (HTML/CSS/JS inline)
├── vercel.json     # Config de deploy estático
```
